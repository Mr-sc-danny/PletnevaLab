# CAVER PyMOL Timeless View

## Purpose

Creates a fixed, frame-independent CAVER tunnel scene for stable inspection and figure preparation.

## Input and calculation

The generated script loads the matching CAVER tunnel and structure assets, then applies a fixed PyMOL style without trajectory animation.

## Usage

Run the dataset-specific `pymol_view_timeless.py` from PyMOL with its generated assets and helper modules.

## Output

Produces a stable PyMOL tunnel scene suitable for saving as an image or session.
