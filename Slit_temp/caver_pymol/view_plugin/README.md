# CAVER PyMOL Plugin View

## Purpose

Bootstraps the generated CAVER PyMOL plugin-style interaction and visualization commands.

## Input and calculation

The script expects generated CAVER plugin assets and helper modules, then registers or initializes the PyMOL commands and UI support.

## Usage

Run the dataset-specific `pymol_view_plugin.py` inside PyMOL with the matching generated files available.

## Output

Produces a PyMOL session with CAVER plugin functionality loaded and ready for interactive use.
