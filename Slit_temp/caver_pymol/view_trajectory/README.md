# CAVER PyMOL Trajectory View

## Purpose

Displays CAVER tunnel geometry across trajectory frames so tunnel changes can be inspected over time.

## Input and calculation

The generated script loads the matching trajectory-aware CAVER objects and configures PyMOL frame navigation and visualization.

## Usage

Run the dataset-specific `pymol_view_trajectory.py` from PyMOL with the matching trajectory, CAVER assets, and helper modules.

## Output

Produces an animated or frame-stepped tunnel visualization that can be saved as a PyMOL session or image sequence.
